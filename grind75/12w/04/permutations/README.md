# Permutations

**Difficulty:** Medium  
**Language:** Java  
**Tags:** `Array` `Backtracking`  
**Time:** O(n*n!)  
**Space:** O(n*n!)

---

## Solution (java)

```java
class Solution {
    List<List<Integer>> ans = new ArrayList<>();
    public List<List<Integer>> permute(int[] nums) {
        boolean[] vis = new boolean[21];
        func(new ArrayList<Integer>(), nums, vis);
        return ans;
    }
    private void func(List<Integer> curr, int[] nums, boolean[] vis){
        if(curr.size()==nums.length){
            ans.add(new ArrayList<>(curr)); 
            return;
        }
        for(int i=0;i<nums.length;i++){
            int num = nums[i];
            if(vis[num+10]) continue;
            vis[num+10] = true; curr.add(num);
            func(curr,nums,vis);
            curr.remove(curr.size()-1); vis[num+10] = false;
        }
    }  
}
```

## Quick Revision
The problem is to generate all permutations of a given array of integers.
We solve it by using backtracking and DFS (Depth-First Search) to explore all possible combinations.

## Intuition
The key insight here is that to generate all permutations, we need to try each element as the first element, then recursively generate all permutations for the remaining elements. This process can be represented as a tree, where each node represents a permutation and its children represent the permutations generated by removing one element from the current permutation.

## Algorithm
1. Initialize an empty list `ans` to store all permutations.
2. Define a helper function `func` that takes three parameters: `curr`, `nums`, and `vis`.
3. In the `func` function, check if the size of `curr` is equal to the length of `nums`. If true, add a copy of `curr` to `ans` and return.
4. Iterate through each element in `nums`. For each element:
	* Check if it's already marked as visited by checking `vis[num+10]`.
	* If not visited, mark it as visited, add it to `curr`, and recursively call `func` with the updated parameters.
	* After recursive call, remove the last added element from `curr` and unmark it as visited for backtracking.

## Concept to Remember
• **Backtracking**: a problem-solving strategy that involves systematically exploring all possible solutions by recursively adding elements to a partial solution until no more solutions can be found.
• **DFS (Depth-First Search)**: a traversal algorithm that explores a graph or tree by visiting a node and then visiting all of its neighbors before backtracking.

## Common Mistakes
• Failing to properly handle the base case, leading to infinite recursion.
• Incorrectly implementing the backtracking mechanism, resulting in duplicate permutations being generated.
• Not handling edge cases, such as an empty input array or an array with repeated elements.

## Complexity Analysis
- Time: O(n*n!) - reason: Each permutation is generated once, and there are n! possible permutations for a list of length n.
- Space: O(n*n!) - reason: The output list `ans` can store up to n! permutations, each of size n.

```java
class Solution {
    List<List<Integer>> ans = new ArrayList<>();
    
    public List<List<Integer>> permute(int[] nums) {
        boolean[] vis = new boolean[21]; // 10 is the maximum possible value in the array + 1, but we add 10 to each num for vis array index
        func(new ArrayList<>(), nums, vis);
        return ans;
    }
    
    private void func(List<Integer> curr, int[] nums, boolean[] vis){
        if(curr.size()==nums.length){ // base case: when the current permutation has the same length as the input array
            ans.add(new ArrayList<>(curr)); 
            return; // add a copy of curr to ans and backtracking
        }
        
        for(int i=0;i<nums.length;i++){
            int num = nums[i];
            if(vis[num+10]) continue; // skip if already visited
            
            vis[num+10] = true; curr.add(num); // mark as visited and add to current permutation
            func(curr, nums, vis); // recursively generate permutations for remaining elements
            curr.remove(curr.size()-1); vis[num+10] = false; // backtrack: remove the last added element and unmark as visited
        }
    }  
}
```
